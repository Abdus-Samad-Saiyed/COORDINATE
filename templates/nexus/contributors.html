How to Contribute to Campus Nexus

Open to NIT Srinagar Students

We welcome code contributions, bug fixes, UI improvements, and new service proposals from all departments and degree programs.

1. Clone & Set Up Locally
git clone https://github.com/abdus-samad-saiyed/Campus-Nexus.git
cd Campus-Nexus
python -m venv venv
pip install -r requirements.txt

Run migrations and seed local debug accounts with python manage.py create_debug_accounts.

2. Pick an Issue or Propose

Browse open tasks in the repository issue tracker, or submit a feature proposal for upcoming modules like print queue or mess menus.

Browse Issues
3. Submit a Pull Request

Ensure all automated unit and integration tests pass (python manage.py test) before submitting your PR.

Open Pull Request
